*********** What is JDK, JRE, JVM *********** 
	
	JDK - Java Development Kit
	it contains tools that developer would need to develop, compile, debug java program
	
	JRE - Java Runtime Environment 
	contains JVM (java virtual machine) and set of libraries that are needed to run java program
	
	JVM - Java Virtual Machine
	it converts bytecode(.class file) to executable code which can run on any platform.
	

*********** What is bytecode *********** 
	 
	Bytecode is middle layer code that gets generated after compilation of java program. java source code (.java) gets 	converted into bytecode which is .class file.
	
*********** What does “write once, run anywhere” ***********
	This flexibility feature of java allows us to write & build java program once. we can execute this complied bytecode on any 	operating system eg. Linux, WIndows, Mac without making any code change.
	Every operating system has its own JVM on which same bytecode can execute on any of OS.
